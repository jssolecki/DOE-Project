### Demonstration Project: Design of Experiments (DOE) Used as a Preprocessing Tool for Machine Leaning.

Refer to _DOE Project Report.pdf_ in this repository for a complete, final report on this project.

**Summary:**

Design of Experiments (DOE) was established as a systematic framework for planning experiments almost 100 years ago. Over the past century DOE served as an important tool for general data engineering through the development of computing and digital data systems. In contemporary AI-driven workflows, the role of DOE  is often forgotten or takes a subordinate role.

Using two examples, this study demonstrated how DOE remains a useful complementary tool for modern modeling workflows with an emphasis on preprocessing. The first example involves a relatively simple problem in nonlinear Newtonian physics and illustrates the development of a DOE-based surrogate model for benchmarking purposes. The second example uses DOE to analyze observational NFL game data. Specifically, each observation represents one game between two NFL teams with the goal of modeling and predicting the final point differential.
